# Usuários e Acessibilidade

**Mapa de Usuários:**
*   **Usuário Primário:** Precisa de uma interface intuitiva. O LED verde indica "tampa fechada/pronto para uso" e o LED apagado indica "tampa aberta/aguarde".
*   **Usuário Secundário (Coleta):** O sistema facilita o trabalho, pois os resíduos já chegam pré-separados nos compartimentos.

**Acessibilidade:**
*   O design não exige força física para abrir a tampa (o servo motor faz isso).
*   O feedback visual (LED) é claro para evitar que o usuário deixe o lixo cair no chão.
*   A abertura automática permite que pessoas com deficiência motora nos membros superiores utilizem a lixeira sem tocar em superfícies potencialmente sujas.
